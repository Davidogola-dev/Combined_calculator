# Combined_calculator
I built this as a first-year Computer Science student while learning Python functions and JavaScript. It started as a few small Python functions mostly specifically eval(),
bin(),chr() and ord(),it just impressed me as i had strangled building simple calculators using if conditions, unfortunately i didn't use eval() since i discovered it had security issues. 
And it grew into a web app that i use together with my classmates mostly in conversation of binary digits use.

What it does

- Math: handles basic mathematical operations
- Bases: converts an integer between binary, octal, decimal and hexadecimal
- Text: shows the binary, octal, decimal and hex codes of any text/character 
- Char to Code / Code to Char: converts between characters and Unicode code points
- Additional features:  history of past calculations, Clear and Copy buttons and friendly error messages instead of crashes

Run it

Click`index.html` to open it in your browser.
